# AI Security Guard — Computer Vision Platform

Модульная платформа видеонаблюдения на Python/Flask с детекцией людей (YOLOv8), распознаванием лиц (InsightFace), анализом зон и веб-интерфейсом.

---

## Структура проекта

```
CV_Platform/
├── web_app.py          # Flask-сервер (основной файл запуска)
├── main.py             # Запуск без веб-интерфейса (только CV-пайплайн)
├── auth.py             # Аутентификация (PBKDF2)
```

## Быстрый старт

### Вариант 1 — Запуск напрямую (Python)

#### 1. Создать виртуальное окружение

```bash
cd CV_Platform
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

#### 2. Установить зависимости

**Если есть NVIDIA GPU:**
```bash
pip install -r requirements.txt
```

**Если GPU нет (только CPU):**
```bash
pip install flask requests numpy opencv-python-headless ultralytics insightface onnxruntime Pillow
```

> ⚠️ `onnxruntime-gpu` требует CUDA 11.8. Если CUDA не установлена — замените на `onnxruntime`.

#### 3. Запустить приложение

```bash
python web_app.py
```

Откройте браузер: **http://localhost:5000**

Логин по умолчанию: `admin` / `admin`

> ⚠️ **Обязательно смените пароль** после первого входа (создайте нового пользователя через `NewUser.py` и удалите `admin`).

### Вариант 2 — Docker (с GPU)

#### Требования
- Docker Desktop с поддержкой NVIDIA GPU
- NVIDIA Container Toolkit

#### Запуск

```bash
cd CV_Platform
docker-compose up --build
```

Откройте: **http://localhost:5000**

#### Остановка

```bash
docker-compose down
```

> **USB-камера в Docker:** если используете USB-камеру (индекс `0`), убедитесь что в `docker-compose.yml` раскомментирована строка `/dev/video0:/dev/video0`. На Windows USB-камера в Docker-контейнере **не поддерживается** — используйте RTSP или запускайте напрямую через Python.

## Первоначальная настройка

### 1. Настройка источника видео

Перейдите в **Settings** (⚙️) и укажите источник:

| Тип | Значение |
|-----|----------|
| Веб-камера (первая) | `0` |
| Веб-камера (вторая) | `1` |
| RTSP-камера | `rtsp://admin:password@192.168.1.64/stream` |
| HTTP-поток | `http://192.168.1.1:8080/video` |
| Видеофайл | `video.mp4` |

### 2. Добавление людей в базу лиц

1. Откройте вкладку **Faces** в навигации
2. Введите имя человека
3. Загрузите чёткое фото лица (JPG/PNG, лицо должно быть хорошо видно)
4. Нажмите **Add Person**

> 💡 Для лучшего качества: фото без очков, анфас, хорошее освещение.

### 3. Добавление нового пользователя

```bash
python NewUser.py <username>
# Пароль будет запрошен интерактивно
```

## Функциональность

### Страницы интерфейса

| URL | Страница | Описание |
|-----|----------|----------|
| `/` | Monitor | Live видеопоток + лог событий в реальном времени |
| `/analytics` | Analytics | Графики посещаемости, топ лиц, почасовая статистика |
| `/faces` | Faces | Добавление/удаление людей из базы распознавания |
| `/zones` | Zone Editor | Рисование зон и линий пересечения поверх кадра |
| `/clips_viewer` | Clips | Просмотр и скачивание записанных видеоклипов |
| `/settings` | Settings | Источник камеры, AI-модули, Telegram-уведомления |

### AI-модули

**People Counting (YOLOv8)**
- Детекция и трекинг людей в кадре
- Отображение траекторий движения
- Поддержка зон: подсчёт людей внутри полигона
- Поддержка линий: счётчик входов/выходов

**Face Recognition (InsightFace)**
- Распознавание по базе известных лиц
- Автозапись видеоклипа при обнаружении
- Cooldown: не пишет одного человека чаще чем раз в N секунд
- Настраиваемый порог совпадения

**Zone Editor**
- Рисование полигональных зон поверх снимка камеры
- Рисование линий пересечения (считают IN/OUT)
- Сохранение в `zones.json`

**Video Buffer**
- Кольцевой буфер: хранит 10 сек до события
- При обнаружении лица: сохраняет клип = 10 сек до + 10 сек после
- Клипы доступны на странице `/clips_viewer`

### Telegram-уведомления

В **Settings** включите Telegram Bot и укажите:
- **Bot Token** — получить у [@BotFather](https://t.me/BotFather)
- **Chat ID** — получить у [@userinfobot](https://t.me/userinfobot)

При каждом распознавании бот пришлёт фото с подписью.

## Решение проблем

**Камера не открывается**
```
Не удалось открыть источник видео: 0
```
- Проверьте что камера не занята другим приложением
- Попробуйте другой индекс (`1`, `2`)
- На Linux: `ls /dev/video*`

**InsightFace не находит лицо на фото**
- Убедитесь что лицо хорошо освещено и видно анфас
- Попробуйте фото с разрешением не менее 200×200 px

**Ошибка CUDA**
```
onnxruntime не может найти GPU
```
- Установите CUDA Toolkit 11.8: https://developer.nvidia.com/cuda-11-8-0-download-archive
- Или используйте CPU-версию: замените `onnxruntime-gpu` на `onnxruntime` в `requirements.txt`

**YOLOv8 скачивает модель при первом запуске**  
Это нормально — `yolov8m.pt` (~52 МБ) скачается автоматически в папку `.cache`. В репозитории уже есть готовые файлы `yolov8m.pt` и `yolov8n.pt`.
